# SDRplay API 3.15 headers

These are the public header files of the SDRplay RSP API version 3.15 (`SDRPLAY_API_VERSION` 3.15), copyright SDRplay
Ltd. They are included only so that the SDRplay driver module (SoapySDRPlay3 plus jSoapySDR's runtime loader) can be
compiled; no SDRplay library is bundled. At runtime the driver uses the SDRplay API that the user installs from
https://www.sdrplay.com/api/.

Source: the SDRplay API 3.15 installer from sdrplay.com. The copies here were taken unmodified from sdrtrunk
(https://github.com/DSheirer/sdrtrunk, `artifacts/sdrplay-api-headers/v3_15/`, commit
728a83a82d952125d93c675280a74a81b94e810e).

The headers contain no license notice of their own; they are governed by SDRplay's API license terms.
